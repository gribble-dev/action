# @gribble/action

This changelog is generated by changesets in the monorepo and copied to
[gribble-dev/action](https://github.com/gribble-dev/action) on every release.
The action's version follows the `gribble` CLI (they share one changesets fixed group), so
`gribble-dev/action@vX.Y.Z` is built from `gribble@X.Y.Z`.

## 0.2.1

### Patch Changes

- First release on `gribble-dev/action`: `uses: gribble-dev/action@v1` runs `gribble audit --ci`, creates the Gribble check run with annotations, maintains the summary and per-finding pull request comments, uploads the run directory as the `gribble-report` artifact, writes SARIF and JUnit files, and can write the baseline back on the default branch.
